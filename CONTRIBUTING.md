# Contributing

Use owned devices or a written, authorized scope. Describe the tested firmware/module/runtime, actual results, and rollback. Keep unknown outcomes pending. Use dummy examples and remove private identifiers from issues and patches. Do not submit credential collection, malware, unrelated traffic interception, jamming, copied branding, or unreviewed recordings.

Preserve provenance and applicable licenses. This repository's original code uses MIT; its intended-use notice is guidance, not an additional license restriction.
