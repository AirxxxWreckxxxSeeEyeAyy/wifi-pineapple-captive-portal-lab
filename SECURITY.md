# Security

This is an alpha lab example, not a hardened production access-control service. The Pineapple management interface, Evil Portal module, device firmware, and their access/logging behavior are outside this package.

Do not post passwords, tokens, personal/device identifiers, client evidence, or private recordings in public issues. Use the repository's private vulnerability-reporting channel if the owner enables one; otherwise ask the maintainer for a private contact without including sensitive details. Reproduce issues with dummy data and owned devices.
